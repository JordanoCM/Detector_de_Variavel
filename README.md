# Detector_de_Variavel
Compilador em JavaCC para linguagem tipada (INT, BOOL, FLOAT, STRING, CHAR). O analisador avalia expressões lógicas/matemáticas, suporta if/else, laços (for) e operadores ternários. Utiliza tabela de símbolos baseada em HashMap para gerenciar e executar o estado das variáveis em tempo real.
